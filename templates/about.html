About This Project

This is an AI-Powered Log Analyzer built as part of an MCA DevOps mini-project.

The Problem: Application servers generate thousands of log lines per hour. Manually reading them to find errors, security threats, or performance issues is impossible.

The Solution: Upload any log file. This application parses it, stores it in MongoDB, uses machine learning (Isolation Forest) to detect anomalies, and displays results on a live dashboard.

Tech Stack

Python / Flask MongoDB scikit-learn Docker GitHub Actions AWS EC2 Prometheus / Grafana
