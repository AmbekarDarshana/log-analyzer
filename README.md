\# AI-Powered Log Analyzer



A web application that ingests application log files, parses them, and

detects unusual patterns using machine learning. Built with a complete

DevOps pipeline including containerization, CI/CD, and monitoring.



\## Project Status



Currently in development.



\- \[x] Flask web application

\- \[x] Log file upload

\- \[x] Log parsing and level analysis

\- \[x] Results dashboard

\- \[ ] MongoDB storage

\- \[ ] Anomaly detection (Isolation Forest)

\- \[ ] Docker containerization

\- \[ ] CI/CD with GitHub Actions

\- \[ ] AWS EC2 deployment

\- \[ ] Prometheus and Grafana monitoring



\## Tech Stack



| Layer | Technology |

|-------|-----------|

| Backend | Python, Flask |

| Database | MongoDB |

| Machine Learning | scikit-learn (Isolation Forest) |

| Frontend | HTML, CSS, Chart.js |

| Containerization | Docker, Docker Compose |

| CI/CD | GitHub Actions |

| Cloud | AWS EC2 |

| Monitoring | Prometheus, Grafana |
